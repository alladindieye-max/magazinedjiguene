# Magazine Djiguene

Projet du site web Magazine Djiguene.

## État du dépôt

Le dépôt sert de source de contrôle de version du projet actuellement déployé sur Vercel.

### Architecture actuelle connue

Le déploiement Vercel existant est un site statique composé notamment de :

- `index.html`
- `index-v2-nuit.html`
- `abonnement.html`
- `robots.txt`
- `sitemap.xml`
- `vercel.json`
- `assets/`
- `images/`

## Règle de récupération

Le code source réel du déploiement existant doit être transféré ici avant toute refonte ou migration.

Ne pas remplacer le projet existant par une version de démonstration.

## Prochaines étapes

1. Récupérer les fichiers du déploiement Vercel existant.
2. Les importer dans ce dépôt sur `main`.
3. Vérifier que le site fonctionne depuis GitHub/Vercel.
4. Mettre en place Supabase pour les fonctionnalités dynamiques.
5. Faire évoluer progressivement le projet avec des commits propres.
